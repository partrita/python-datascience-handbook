Scikit-Learn 소개

다양한 머신러닝(Machine Learning) 알고리즘의 견고한 구현을 제공하는 여러 파이썬(Python) 라이브러리가 있습니다. 가장 잘 알려진 것 중 하나는 다수의 일반 알고리즘의 효율적인 버전을 제공하는 패키지인 Scikit-Learn입니다. Scikit-Learn은 매우 유용하고 완전한 온라인 문서뿐만 아니라 깔끔하고 균일하며 간소화된 API가 특징입니다. 이러한 통일성의 이점은 한 가지 모델 유형에 대한 Scikit-Learn의 기본 사용과 구문을 이해하고 나면 새 모델이나 알고리즘으로 전환하는 것이 간단하다는 것입니다.

이번 장에서는 Scikit-Learn API의 개요를 제공합니다. 이러한 API 요소에 대한 확실한 이해는 다음 장에서 머신러닝(Machine Learning) 알고리즘 및 접근 방식에 대한 보다 심층적이고 실용적인 논의를 이해하기 위한 기반을 형성합니다.

먼저 Scikit-Learn의 데이터 표현을 다룬 다음 Estimator API를 자세히 살펴보고 마지막으로 손으로 쓴 숫자 이미지 세트를 탐색하기 위해 이러한 도구를 사용하는 보다 흥미로운 예를 살펴보겠습니다.

Scikit-Learn의 데이터 표현

머신러닝은 데이터로부터 모델을 생성하는 것입니다. 따라서 먼저 데이터를 표현하는 방법에 대해 논의하겠습니다. Scikit-Learn 내에서 데이터를 생각하는 가장 좋은 방법은 테이블을 사용하는 것입니다.

기본 테이블은 데이터의 2차원 그리드로, 행은 데이터세트의 개별 요소를 나타내고 열은 이러한 각 요소와 관련된 수량을 나타냅니다. 예를 들어 1936년 Ronald Fisher가 분석한 것으로 유명한 Iris 데이터세트를 생각해 보세요. Seaborn 라이브러리를 사용하여 Pandas DataFrame 형식으로 이 데이터 세트를 다운로드하고 처음 몇 가지 항목을 살펴살펴볼 수 있습니다.

import seaborn as sns
iris = sns.load_dataset('iris')
iris.head()
sepal_length sepal_width petal_length petal_width species
0 5.1 3.5 1.4 0.2 setosa
1 4.9 3.0 1.4 0.2 setosa
2 4.7 3.2 1.3 0.2 setosa
3 4.6 3.1 1.5 0.2 setosa
4 5.0 3.6 1.4 0.2 setosa

여기서 데이터의 각 행은 관찰된 단일 꽃을 나타내며 행 수는 데이터세트에 있는 총 꽃 수입니다. 일반적으로 행렬의 행을 samples로 참조하고 행 수를 n_samples로 참조합니다.

마찬가지로, 데이터의 각 열은 각 샘플을 설명하는 특정 정량적 정보를 나타냅니다. 일반적으로 행렬의 열을 features로 참조하고 열 수를 n_features로 참조합니다.

기능 매트릭스

테이블 레이아웃은 정보가 2차원 숫자 배열 또는 매트릭스(기능 매트릭스라고 함)로 간주될 수 있음을 명확하게 보여줍니다. 관례적으로 이 행렬은 ’X’라는 변수에 저장되는 경우가 많습니다. 특성 행렬은 [n_samples, n_features] 형태의 2차원으로 가정되며 NumPy 배열 또는 Pandas DataFrame에 가장 자주 포함되지만 일부 Scikit-Learn 모델은 SciPy 희소 행렬도 허용합니다.

샘플(즉, 행)은 항상 데이터세트에서 설명하는 개별 개체를 참조합니다. 예를 들어 샘플은 꽃, 사람, 문서, 이미지, 사운드 파일, 비디오, 천체 또는 일련의 정량적 측정으로 설명할 수 있는 모든 것을 나타낼 수 있습니다.

특징(즉, 열)은 항상 각 샘플을 정량적 방식으로 설명하는 고유한 관찰을 나타냅니다. 기능은 실수 값인 경우가 많지만 경우에 따라 부울 값이거나 이산 값일 수도 있습니다.

대상 배열

특징 매트릭스 X 외에도 일반적으로 label 또는 target 배열을 사용하여 작업하며, 일반적으로 이를 y라고 부릅니다. 대상 배열은 일반적으로 길이가 n_samples인 1차원이며 일반적으로 NumPy 배열 또는 Pandas Series에 포함됩니다. 대상 배열에는 연속적인 숫자 값이 있거나 개별 클래스/레이블이 있을 수 있습니다. 일부 Scikit-Learn 추정기는 2차원 [n_samples, n_targets] 대상 배열 형태로 여러 대상 값을 처리하지만, 우리는 주로 1차원 대상 배열의 일반적인 경우로 작업할 것입니다.

흔히 혼동되는 점은 대상 배열이 다른 특성 열과 어떻게 다른지입니다. 대상 배열의 구별되는 특징은 일반적으로 우리가 특징에서 예측하려는 수량이라는 것입니다. 즉, 통계적 측면에서 이는 종속 변수입니다. 예를 들어 이전 데이터가 주어지면 다른 측정값을 기반으로 꽃의 종류를 예측할 수 있는 모델을 구축할 수 있습니다. 이 경우 species 열은 대상 배열로 간주됩니다.

이 대상 배열을 염두에 두고 Seaborn(Visualization With Seaborn에서 설명)을 사용하여 데이터를 편리하게 시각화할 수 있습니다(다음 그림 참조).

%matplotlib inline
import seaborn as sns
sns.pairplot(iris, hue='species', height=1.5);

Scikit-Learn에서 사용하기 위해 DataFrame에서 기능 매트릭스와 대상 배열을 추출합니다. 이는 3부에서 설명한 Pandas DataFrame 작업 중 일부를 사용하여 수행할 수 있습니다.

X_iris = iris.drop('species', axis=1)
X_iris.shape
(150, 4)
y_iris = iris['species']
y_iris.shape
(150,)

요약하면 예상되는 특성 및 대상 값의 레이아웃이 다음 그림에 시각화되어 있습니다.

부록의 그림 소스

이 데이터의 형식이 적절하면 Scikit-Learn의 Estimator API를 고려할 수 있습니다.

추정기 API

Scikit-Learn API는 Scikit-Learn API 문서에 설명된 대로 다음 지침 원칙을 염두에 두고 설계되었습니다.

  • 일관성: 모든 개체는 일관된 문서를 통해 제한된 메서드 집합에서 가져온 공통 인터페이스를 공유합니다.

  • 검사: 지정된 모든 매개변수 값이 공개 속성으로 노출됩니다.

  • 제한된 개체 계층: 알고리즘만 파이썬(Python) 클래스로 표현됩니다. 데이터세트가 표현됩니다 표준 형식(NumPy 배열, Pandas DataFrame 객체, SciPy 희소 행렬) 및 매개변수 이름은 표준 파이썬(Python) 문자열을 사용합니다.

  • 구성: 많은 머신러닝(Machine Learning) 작업은 보다 기본적인 알고리즘의 시퀀스로 표현될 수 있습니다. Scikit-Learn은 가능한 경우 이를 활용합니다.

  • 합리적인 기본값: 모델에 사용자 지정 매개변수가 필요한 경우 라이브러리는 적절한 기본값을 정의합니다.

실제로 이러한 원칙을 통해 기본 원칙을 이해하면 Scikit-Learn을 매우 쉽게 사용할 수 있습니다. Scikit-Learn의 모든 머신러닝(Machine Learning) 알고리즘은 광범위한 머신러닝(Machine Learning) 애플리케이션에 일관된 인터페이스를 제공하는 Estimator API를 통해 구현됩니다.

API의 기본

가장 일반적으로 Scikit-Learn Estimator API를 사용하는 단계는 다음과 같습니다.

  1. Scikit-Learn에서 적절한 추정기 클래스를 가져와 모델 클래스를 선택합니다.
  2. 이 클래스를 원하는 값으로 인스턴스화하여 모델 하이퍼파라미터를 선택합니다.
  3. 이 장의 앞부분에서 설명한 대로 데이터를 특징 매트릭스와 대상 벡터로 정렬합니다.
  4. 모델 인스턴스의 ‘fit’ 메서드를 호출하여 모델을 데이터에 맞춥니다.
  5. 새 데이터에 모델을 적용합니다.
  • 지도 학습의 경우 ‘예측’ 방법을 사용하여 알려지지 않은 데이터에 대한 레이블을 예측하는 경우가 많습니다.
  • 비지도 학습의 경우 변환 또는 예측 방법을 사용하여 데이터의 속성을 변환하거나 추론하는 경우가 많습니다.

이제 지도 및 비지도 학습 방법을 적용하는 몇 가지 간단한 예를 단계별로 살펴보겠습니다.

지도 학습 예시: 단순 선형 회귀

이 프로세스의 예로 간단한 선형 회귀, 즉 \((x, y)\) 데이터에 선을 맞추는 일반적인 경우를 고려해 보겠습니다. 회귀 예제에서는 다음과 같은 간단한 데이터를 사용합니다(다음 그림 참조).

import matplotlib.pyplot as plt
import numpy as np

rng = np.random.RandomState(42)
x = 10 * rng.rand(50)
y = 2 * x - 1 + rng.randn(50)
plt.scatter(x, y);

이 데이터가 있으면 앞서 설명한 방법을 사용할 수 있습니다. 프로세스를 살펴보겠습니다.

1. 모델 클래스를 선택하세요.

Scikit-Learn에서 모델의 모든 클래스는 파이썬(Python) 클래스로 표현됩니다. 예를 들어 간단한 LinearRegression 모델을 계산하려는 경우 선형 회귀 클래스를 가져올 수 있습니다.

from sklearn.linear_model import LinearRegression

다른 보다 일반적인 선형 회귀 모델도 존재합니다. 이에 대한 자세한 내용은 sklearn.linear_model 모듈 문서에서 읽을 수 있습니다.

2. 모델 하이퍼파라미터 선택

중요한 점은 모델의 클래스가 모델의 인스턴스와 동일하지 않다는 것입니다.

모델 클래스를 결정한 후에도 여전히 몇 가지 옵션이 열려 있습니다. 작업 중인 모델 클래스에 따라 다음과 같은 하나 이상의 질문에 대답해야 할 수도 있습니다.

  • 오프셋(즉, y절편)에 적합하시겠습니까?
  • 모델을 정규화하시겠습니까?
  • 모델 유연성을 추가하기 위해 기능을 전처리하고 싶습니까?
  • 모델에 어느 정도의 정규화를 사용하고 싶나요?
  • 얼마나 많은 모델 구성 요소를 사용하고 싶습니까?

다음은 모델 클래스가 선택된 후 이루어져야 하는 중요한 선택의 예입니다. 이러한 선택은 종종 초매개변수 또는 모델이 데이터에 적합하기 전에 설정해야 하는 매개변수로 표시됩니다. Scikit-Learn에서 하이퍼파라미터는 모델 인스턴스화 시 값을 전달하여 선택됩니다. 하이퍼파라미터 및 모델 검증에서 하이퍼파라미터를 정량적으로 선택하는 방법을 살펴보겠습니다.

선형 회귀 예제의 경우 LinearRegression 클래스를 인스턴스화하고 fit_intercept 하이퍼파라미터를 사용하여 절편을 맞추도록 지정할 수 있습니다.

model = LinearRegression(fit_intercept=True)
model
LinearRegression()

모델이 인스턴스화될 때 유일한 작업은 이러한 하이퍼파라미터 값을 저장하는 것입니다. 특히, 우리는 아직 어떤 데이터에도 모델을 적용하지 않았습니다. Scikit-Learn API는 모델 선택과 모델을 데이터에 적용 간의 차이를 매우 명확하게 만듭니다.

3. 데이터를 특징 행렬과 목표 벡터로 배열합니다.

이전에 우리는 2차원 특징 행렬과 1차원 목표 배열이 필요한 Scikit-Learn 데이터 표현을 조사했습니다. 여기서 목표 변수 y는 이미 올바른 형식(길이-n_samples 배열)이지만 데이터 x를 마사지하여 [n_samples, n_features] 크기의 행렬로 만들어야 합니다. 이 경우 이는 1차원 배열의 간단한 재구성에 해당합니다.

X = x[:, np.newaxis]
X.shape
(50, 1)

4. 모델을 데이터에 맞춤

이제 모델을 데이터에 적용할 차례입니다. 이는 모델의 ‘fit’ 메소드를 사용하여 수행할 수 있습니다.

model.fit(X, y)
LinearRegression()

이 ‘fit’ 명령을 사용하면 모델에 따른 여러 내부 계산이 발생하고 이러한 계산 결과는 사용자가 탐색할 수 있는 모델별 속성에 저장됩니다. Scikit-Learn에서는 관례적으로 ‘fit’ 프로세스 중에 학습된 모든 모델 매개변수에 밑줄이 붙습니다. 예를 들어 이 선형 모델에는 다음이 있습니다.

model.coef_
array([1.9776566])
model.intercept_
-0.9033107255311146

이 두 매개변수는 데이터에 대한 단순 선형 적합의 기울기와 절편을 나타냅니다. 결과를 데이터 정의와 비교하면 데이터를 생성하는 데 사용된 값인 기울기 2와 절편 -1에 가깝다는 것을 확인할 수 있습니다.

자주 제기되는 질문 중 하나는 그러한 내부 모델 매개변수의 불확실성에 관한 것입니다. 일반적으로 Scikit-Learn은 내부 모델 매개변수 자체에서 결론을 도출하는 도구를 제공하지 않습니다. 모델 매개변수 해석은 머신러닝 질문이라기보다는 통계적 모델링 질문에 훨씬 가깝습니다. 대신 머신러닝은 모델이 예측하는 내용에 중점을 둡니다. 모델 제 맞춤 매개변수의 의미를 자세히 알아보려면 statsmodels 파이썬(Python) 패키지를 비롯한 다른 도구를 사용할 수 있습니다.

5. 알 수 없는 데이터에 대한 레이블 예측

모델이 훈련되면 지도 머신러닝(Machine Learning)의 주요 작업은 훈련 세트에 포함되지 않은 새로운 데이터에 대해 말하는 내용을 기반으로 모델을 평가하는 것입니다. Scikit-Learn에서는 predict 방법을 사용하여 이를 수행할 수 있습니다. 이 예의 경우 “새 데이터”는 x 값의 그리드가 되며 모델이 예측하는 y 값이 무엇인지 묻습니다.

xfit = np.linspace(-1, 11)

이전과 마찬가지로 이러한 x 값을 [n_samples, n_features] 기능 매트릭스로 강제 변환한 후 이를 모델에 제공할 수 있습니다.

Xfit = xfit[:, np.newaxis]
yfit = model.predict(Xfit)

마지막으로, 먼저 원시 데이터를 플로팅한 후 이 모델을 피팅하여 결과를 시각화해 보겠습니다(다음 그림 참조).

plt.scatter(x, y)
plt.plot(xfit, yfit);

일반적으로 모델의 효율성은 다음 예에서 볼 수 있듯이 결과를 알려진 기준선과 비교하여 평가됩니다.

지도 학습 예시: 붓꽃 분류

앞서 논의한 Iris 데이터 세트를 사용하여 이 프로세스의 또 다른 예를 살펴보겠습니다. 우리의 질문은 다음과 같습니다: Iris 데이터의 일부에 대해 훈련된 모델이 주어지면 나머지 레이블을 얼마나 잘 예측할 수 있습니까?

이 작업에서는 Gaussian naive Bayes라는 간단한 생성 모델을 사용합니다. 이 모델은 각 클래스가 축 정렬된 가우스 분포에서 추출된다고 가정하여 진행됩니다(자세한 내용은 In Depth: Naive Bayes Classification 참조). 매우 빠르고 선택할 하이퍼파라미터가 없기 때문에 Gaussian Naive Bayes는 보다 정교한 모델을 통해 개선 사항을 찾을 수 있는지 탐색하기 전에 기준 분류로 사용하기에 좋은 모델인 경우가 많습니다.

이전에 본 적이 없는 데이터로 모델을 평가하고 싶기 때문에 데이터를 훈련 세트와 테스트 세트로 분할하겠습니다. 이 작업은 직접 수행할 수도 있지만 train_test_split 유틸리티 함수를 사용하는 것이 더 편리합니다.

from sklearn.model_selection import train_test_split
Xtrain, Xtest, ytrain, ytest = train_test_split(X_iris, y_iris,
                                                random_state=1)

데이터가 정렬되면 레시피에 따라 라벨을 예측할 수 있습니다.

from sklearn.naive_bayes import GaussianNB # 1. choose model class
model = GaussianNB()                       # 2. instantiate model
model.fit(Xtrain, ytrain)                  # 3. fit model to data
y_model = model.predict(Xtest)             # 4. predict on new data

마지막으로 accuracy_score 유틸리티를 사용하여 실제 값과 일치하는 예측 라벨의 비율을 확인할 수 있습니다.

from sklearn.metrics import accuracy_score
accuracy_score(ytest, y_model)
0.9736842105263158

97%에 달하는 정확도로 매우 순진한 분류 알고리즘도 이 특정 데이터 세트에 효과적이라는 것을 알 수 있습니다!

비지도 학습 예시: 홍채 차원

비지도 학습 문제의 예로 붓꽃 데이터를 보다 쉽게 ​​시각화하기 위해 차원을 줄이는 방법을 살펴보겠습니다. 홍채 데이터는 4차원입니다. 각 샘플에 대해 4가지 특징이 기록됩니다.

차원 축소 작업은 데이터의 필수 기능을 유지하는 적절한 하위 차원 표현이 있는지 여부를 결정하는 데 중점을 둡니다. 종종 차원 축소는 데이터 시각화를 돕기 위해 사용됩니다. 결국 데이터를 4차원 이상으로 그리는 것보다 2차원으로 그리는 것이 훨씬 쉽습니다!

여기서는 빠른 선형 차원 축소 기법인 주성분 분석(PCA, 심층: 주성분 분석 참조)을 사용하겠습니다. 모델에 두 가지 구성 요소, 즉 데이터의 2차원 표현을 반환하도록 요청합니다.

앞서 설명한 일련의 단계를 따르면 다음과 같습니다.

from sklearn.decomposition import PCA  # 1. Choose the model class
model = PCA(n_components=2)            # 2. Instantiate the model
model.fit(X_iris)                      # 3. Fit to data
X_2D = model.transform(X_iris)         # 4. Transform the data

이제 결과를 플롯해 보겠습니다. 이를 수행하는 빠른 방법은 결과를 원본 Iris ’DataFrame’에 삽입하고 Seaborn의 ’lmplot’을 사용하여 결과를 표시하는 것입니다(다음 그림 참조).

iris['PCA1'] = X_2D[:, 0]
iris['PCA2'] = X_2D[:, 1]
sns.lmplot(x="PCA1", y="PCA2", hue='species', data=iris, fit_reg=False);

PCA 알고리즘이 종 라벨에 대한 지식이 없음에도 불구하고 2차원 표현에서 종은 상당히 잘 분리되어 있음을 알 수 있습니다! 이는 이전에 살펴본 것처럼 상대적으로 간단한 분류가 데이터세트에 효과적일 수 있음을 시사합니다.

비지도 학습 예시: 붓꽃 클러스터링

다음으로는 Iris 데이터에 클러스터링을 적용하는 방법을 살펴보겠습니다. 클러스터링 알고리즘은 레이블을 참조하지 않고 고유한 데이터 그룹을 찾으려고 시도합니다. 여기서는 가우스 혼합 모델(GMM)이라는 강력한 클러스터링 방법을 사용합니다. 자세한 내용은 심층: 가우스 혼합 모델에서 설명합니다. GMM은 데이터를 가우스 얼룩 모음으로 모델링하려고 시도합니다.

가우스 혼합 모델은 다음과 같이 적합할 수 있습니다.

from sklearn.mixture import GaussianMixture      # 1. Choose the model class
model = GaussianMixture(n_components=3,
                        covariance_type='full')  # 2. Instantiate the model
model.fit(X_iris)                                # 3. Fit to data
y_gmm = model.predict(X_iris)                    # 4. Determine labels

이전과 마찬가지로 Iris DataFrame에 클러스터 라벨을 추가하고 Seaborn을 사용하여 결과를 플롯합니다(다음 그림 참조).

iris['cluster'] = y_gmm
sns.lmplot(x="PCA1", y="PCA2", data=iris, hue='species',
           col='cluster', fit_reg=False);

데이터를 클러스터 번호로 분할함으로써 GMM 알고리즘이 기본 레이블을 얼마나 잘 복구했는지 정확히 확인할 수 있습니다. setosa 종은 클러스터 0 내에서 완벽하게 분리되는 반면 versicolor와 virginica 사이에는 약간의 혼합이 남아 있습니다. 이는 전문가가 개별 꽃의 종 라벨을 알려주지 않아도 이러한 꽃의 측정값이 충분히 뚜렷하기 때문에 간단한 클러스터링 알고리즘을 사용하여 이러한 다양한 종 그룹의 존재를 자동으로 식별할 수 있다는 의미입니다! 이러한 종류의 알고리즘은 현장 전문가에게 관찰 중인 샘플 간의 관계에 대한 단서를 제공할 수 있습니다.

응용 프로그램: 손으로 쓴 숫자 탐색

보다 흥미로운 문제에 대한 이러한 원리를 입증하기 위해 광학 문자 인식 문제의 한 부분인 손으로 쓴 숫자 식별을 고려해 보겠습니다. 실제로 이 문제는 이미지에서 문자를 찾고 식별하는 것과 관련됩니다. 여기서는 바로가기를 사용하여 라이브러리에 내장된 Scikit-Learn의 미리 형식화된 숫자 집합을 사용하겠습니다.

숫자 데이터 로드 및 시각화

Scikit-Learn의 데이터 액세스 인터페이스를 사용하여 이 데이터를 살펴살펴볼 수 있습니다.

from sklearn.datasets import load_digits
digits = load_digits()
digits.images.shape
(1797, 8, 8)

이미지 데이터는 3차원 배열입니다. 각각 8 × 8 픽셀 그리드로 구성된 1,797개 샘플입니다. 이들 중 처음 100개를 시각화해 보겠습니다(다음 그림 참조).

import matplotlib.pyplot as plt

fig, axes = plt.subplots(10, 10, figsize=(8, 8),
                         subplot_kw={'xticks':[], 'yticks':[]},
                         gridspec_kw=dict(hspace=0.1, wspace=0.1))

for i, ax in enumerate(axes.flat):
    ax.imshow(digits.images[i], cmap='binary', interpolation='nearest')
    ax.text(0.05, 0.05, str(digits.target[i]),
            transform=ax.transAxes, color='green')

Scikit-Learn 내에서 이 데이터를 사용하려면 2차원 [n_samples, n_features] 표현이 필요합니다. 이미지의 각 픽셀을 특징으로 처리하여 이를 수행할 수 있습니다. 즉, 픽셀 배열을 평면화하여 각 숫자를 나타내는 픽셀 값의 길이가 64인 배열을 갖게 됩니다. 또한 각 숫자에 대해 이전에 결정된 레이블을 제공하는 대상 배열이 필요합니다. 이 두 수량은 각각 ‘data’ 및 ‘target’ 속성 아래 숫자 데이터세트에 내장되어 있습니다.

X = digits.data
X.shape
(1797, 64)
y = digits.target
y.shape
(1797,)

여기에는 1,797개의 샘플과 64개의 기능이 있음을 확인할 수 있습니다.

비지도 학습 예시: 차원 축소

우리는 64차원 매개변수 공간 내에서 점을 시각화하고 싶지만 이러한 고차원 공간에서는 점을 효과적으로 시각화하기가 어렵습니다. 대신 비지도 방법을 사용하여 차원 수를 줄입니다. 여기서는 Isomap이라는 다양한 학습 알고리즘을 사용하고(심층: 다양체 학습 참조) 데이터를 2차원으로 변환합니다.

from sklearn.manifold import Isomap
iso = Isomap(n_components=2)
iso.fit(digits.data)
data_projected = iso.transform(digits.data)
print(data_projected.shape)
(1797, 2)

이제 투영된 데이터가 2차원임을 확인할 수 있습니다. 이 데이터를 플롯하여 구조에서 무엇인가 배울 수 있는지 살펴보겠습니다(다음 그림 참조).

plt.scatter(data_projected[:, 0], data_projected[:, 1], c=digits.target,
            edgecolor='none', alpha=0.5,
            cmap=plt.cm.get_cmap('viridis', 10))
plt.colorbar(label='digit label', ticks=range(10))
plt.clim(-0.5, 9.5);

이 플롯은 더 큰 64차원 공간에서 다양한 숫자가 얼마나 잘 분리되어 있는지에 대한 좋은 직관을 제공합니다. 예를 들어 0과 1은 매개변수 공간에서 거의 겹치지 않습니다. 직관적으로 이는 의미가 있습니다. 0은 이미지 중앙이 비어 있는 반면 1은 일반적으로 중앙에 잉크가 있습니다. 반면에 1과 4 사이에는 다소 연속적인 스펙트럼이 있는 것 같습니다. 어떤 사람들은 “모자”가 있는 1을 그리므로 4와 유사하게 보인다는 사실을 통해 이를 이해할 수 있습니다.

그러나 전반적으로 가장자리에서의 일부 혼합에도 불구하고 다양한 그룹은 매개변수 공간에서 상당히 잘 국한된 것으로 보입니다. 이는 매우 간단한 감독 분류 알고리즘이라도 전체 고차원 데이터 세트에서 적절하게 수행되어야 함을 의미합니다. 한번 시도해 봅시다.

숫자 분류

숫자 데이터에 분류 알고리즘을 적용해 보겠습니다. 이전에 Iris 데이터에서 했던 것처럼 데이터를 훈련 및 테스트 세트로 분할하고 Gaussian Naive Bayes 모델을 적용합니다.

Xtrain, Xtest, ytrain, ytest = train_test_split(X, y, random_state=0)
from sklearn.naive_bayes import GaussianNB
model = GaussianNB()
model.fit(Xtrain, ytrain)
y_model = model.predict(Xtest)

이제 모델의 예측이 있으므로 테스트 세트의 실제 값을 예측과 비교하여 정확도를 측정할 수 있습니다.

from sklearn.metrics import accuracy_score
accuracy_score(ytest, y_model)
0.8333333333333334

이는 라벨이 잘못 지정된 지점이 어디인지 보여줍니다. 예를 들어 여기 있는 2개 중 다수가 1개 또는 8개로 잘못 분류되었습니다.

모델의 특성에 대한 직관을 얻는 또 다른 방법은 예측된 레이블을 사용하여 입력을 다시 플롯하는 것입니다. 올바른 라벨에는 녹색을 사용하고 잘못된 라벨에는 빨간색을 사용합니다. 다음 그림을 참조하세요.
