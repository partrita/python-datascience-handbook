## 주피터 노트북 실행하기

Python/IPython 문을 실행할 뿐만 아니라 노트북을 사용하면 서식 있는 텍스트, 정적 및 동적 시각화, 수학 방정식, JavaScript 위젯 등을 포함할 수 있습니다.

웹 브라우저 창을 통해 Jupyter 노트북을 보고 편집하더라도 코드를 실행하려면 실행 중인 Python 프로세스에 연결해야 합니다.

## IPython의 도움말 및 문서

이 장의 다른 섹션을 읽지 않았다면 다음 섹션을 읽어보세요. 여기에서 논의된 도구는 내 일상 작업 흐름에 IPython이 가장 혁신적인 기여를 한 것이라고 생각합니다.

기술적인 생각을 가진 사람이 컴퓨터 문제로 친구, 가족, 동료를 도와달라고 요청받을 때, 대부분의 경우 답을 아는 것보다 알려지지 않은 답을 빨리 찾는 방법을 아는 것이 더 중요합니다.
데이터 과학에서도 마찬가지입니다. 온라인 문서, 메일링 리스트 스레드, 스택 오버플로 답변과 같은 검색 가능한 웹 리소스에는 풍부한 정보가 포함되어 있으며, 심지어 이전에 검색했던 주제에 대해서도 (특히?) 정보가 포함되어 있습니다.
효과적인 데이터 과학 실무자가 된다는 것은 가능한 모든 상황에 사용해야 하는 도구나 명령을 암기하는 것보다 웹 검색 엔진이나 다른 수단을 통해 모르는 정보를 효과적으로 찾는 방법을 배우는 것입니다.

IPython/Jupyter의 가장 유용한 기능 중 하나는 사용자와 사용자가 작업을 효과적으로 수행하는 데 도움이 되는 문서 및 검색 유형 간의 격차를 줄이는 것입니다.
웹 검색은 여전히 ​​복잡한 질문에 답하는 역할을 하고 있지만, IPython만으로도 엄청난 양의 정보를 찾을 수 있습니다.
IPython이 몇 가지 키 입력으로 답변하는 데 도움이 될 수 있는 질문의 몇 가지 예는 다음과 같습니다.

- 이 함수를 어떻게 호출하나요? 어떤 주장과 옵션이 있습니까?
- 이 Python 객체의 소스 코드는 어떤 모습인가요?
- 내가 가져온 이 패키지에는 무엇이 들어있나요?
- 이 객체에는 어떤 속성이나 메소드가 있습니까?

여기에서는 이 정보에 빠르게 액세스하기 위해 IPython 셸과 Jupyter Notebook에서 제공되는 도구, 즉 문서 탐색을 위한 `?` 문자, 소스 코드 탐색을 위한 `??` 문자, 자동 완성을 위한 Tab 키에 대해 설명합니다.

### ?로 문서에 액세스하려면?

Python 언어와 해당 데이터 과학 생태계는 사용자를 염두에 두고 구축되었으며, 그 중 가장 큰 부분은 문서에 대한 액세스입니다.
모든 Python 객체에는 *docstring*이라고 알려진 문자열에 대한 참조가 포함되어 있으며, 대부분의 경우 객체에 대한 간략한 요약과 사용 방법이 포함됩니다.
Python에는 이 정보에 액세스하고 결과를 인쇄할 수 있는 'help' 함수가 내장되어 있습니다.
예를 들어 내장 `len` 함수의 문서를 보려면 다음을 수행하면 됩니다.

``ipython

객체에 대한 도움말을 찾는 것은 매우 일반적이고 유용하기 때문에 IPython과 Jupyter는 이 문서 및 기타 관련 정보에 액세스하기 위한 약칭으로 ‘?’ 문자를 도입합니다.

### ??로 소스 코드에 접근하기

Python 언어는 읽기가 매우 쉽기 때문에 일반적으로 궁금한 개체의 소스 코드를 읽으면 또 다른 수준의 통찰력을 얻을 수 있습니다.
IPython과 Jupyter는 이중 물음표(`??`)를 사용하여 소스 코드에 대한 바로 가기를 제공합니다.

``ipython

파일: <ipython-input-6>
유형: 기능

이와 같은 간단한 기능의 경우 이중 물음표를 사용하면 내부 세부 정보에 대한 빠른 통찰력을 얻을 수 있습니다.

이것저것 많이 가지고 놀다 보면 때로는 ?? 접미사가 어떤 소스 코드도 표시하지 않는다는 것을 알게 될 것입니다. 이는 일반적으로 문제의 객체가 Python이 아니라 C 또는 다른 컴파일된 확장 언어로 구현되기 때문입니다. 이 경우 ?? 접미사는 ? 접미사와 동일한 출력을 제공합니다. 특히 이전의 len 함수를 포함하여 Python의 많은 내장 객체 및 유형에서 이를 찾을 수 있습니다.

``ipython [9]에서: len?? 서명: len(obj, /) Docstring: 컨테이너에 있는 항목 수를 반환합니다. 유형: 내장_함수_또는_방법


`?` 및/또는 `??`를 사용하는 것은 Python 함수나 모듈이 수행하는 작업에 대한 정보를 찾는 강력하고 빠른 방법입니다.

#### 탭 완성 이후: 와일드카드 일치

탭 완성은 찾고 있는 개체나 속성 이름의 처음 몇 글자를 알고 있는 경우 유용하지만, 이름 중간이나 끝의 문자를 일치시키려는 경우에는 거의 도움이 되지 않습니다.
이 사용 사례의 경우 IPython과 Jupyter는 '*' 문자를 사용하여 이름에 대한 와일드카드 일치 방법을 제공합니다.

예를 들어, 이를 사용하여 이름이 `Warning`으로 끝나는 네임스페이스의 모든 객체를 나열할 수 있습니다.

``ipython
[10]에서: *경고?
바이트 경고 런타임 경고
사용 중단경고 구문Warning
FutureWarning 유니코드경고
가져오기 경고 사용자 경고
보류 중지원 중단경고 경고
자원경고

* 문자는 빈 문자열을 포함한 모든 문자열과 일치합니다.

마찬가지로 이름 어딘가에 ’find’라는 단어가 포함된 문자열 메서드를 찾고 있다고 가정해 보겠습니다. 다음과 같은 방법으로 검색할 수 있습니다.

``ipython [11]에서: str.find? str.find str.rfind ````

이러한 유형의 유연한 와일드카드 검색은 새로운 패키지를 알아보거나 익숙한 패키지를 다시 알아볼 때 특정 명령을 찾는 데 유용할 수 있습니다.
